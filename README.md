# Portafolio digital · Gestión de la Información y del Aprendizaje

Portafolio digital elaborado para el **Producto Académico N.º 2** (Unidad 2) de la
asignatura *Gestión de la Información y del Aprendizaje* — Universidad Continental.

**Sitio publicado:** https://9yinsk.github.io/portafolio-gia/

Tema: **grafos de conocimiento y generación aumentada por recuperación (RAG)** — cómo se
organiza la información para que un sistema de inteligencia artificial responda a partir de
fuentes verificables en lugar de inventar.

## Estructura

| Página | Contenido |
|---|---|
| `index.html` | Presentación y mapa del portafolio |
| `01-definicion.html` | Definición del proyecto, autoeficacia y planificación |
| `02-busqueda.html` | Estrategia de búsqueda, repositorios y ficha crítica de las fuentes |
| `03-contenido.html` | Contenido multiformato y formación continua |
| `04-ia.html` | Aplicaciones de la IA en el ámbito académico y herramientas usadas |
| `05-publicacion.html` | Publicación, difusión, licencias y referencias |

El sitio se genera con los scripts `build.py` y `p1.py` … `p5.py` (Python, sin dependencias):

```
python p1.py && python p2.py && python p3.py && python p4.py && python p5.py
```
